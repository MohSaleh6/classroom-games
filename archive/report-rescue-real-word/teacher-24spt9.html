Report Rescue: Save the School Magazine!

Students are magazine editors. They copy a messy starter report into Microsoft Word and fix it in 5 missions, one for each lesson in Unit 1. The game guides the work; every task is done in Word. Each student finishes with one complete, saved report.

Important: the game cannot read Word files. Students tick tasks to claim points. You confirm the real score by checking the Word file and stamping their badge with your teacher code (see Scoring). The only thing the game checks itself is the 5 spelling words students type in Mission 5.

Preparation

✅ Before class (5 minutes)

  • Test the student link on one class computer. Make sure Word opens.
  • Create a shared class folder for saving files (students save as ReportRescue_TheirName).
  • Stock Images and 3D Models need Microsoft 365 and internet. No internet? Put 3–4 topic pictures in the class folder. Students use Insert → Pictures → This Device.
  • Older Word with no 3D Models button: students use the alternative (Picture Effects → 3-D Rotation). It earns full points.
  • Optional: set your own report layout and teacher code below, then share the class link instead of the plain link.
  • Decide if students will print today. The game tells them to stop at Print Preview.
Points and badges

⭐ Scoring

How points work

  • Students tap I did it in Word to claim each task’s points. These are claimed points, not final.
  • The Ready to Publish badge unlocks when every task on the student’s route is claimed.
  • On the 🏁 screen, tap Teacher: verify this report. Open the student’s Word file, untick anything you cannot see, set how many spelling mistakes are really fixed, and enter your teacher code.
  • The stamp shows the verified score and a rank. Ranks use a percentage, so both routes can earn every rank.
  • Bonus points (up to +10) are shown separately and do not change the rank.

    Differentiation

    🛟 Support Route

    • Students choose it on the start screen. It is never labelled as “easier” to classmates; it shows as a route choice.
    • 19 key tasks instead of 26 (73 points). Skipped: byline, bold-italic name, spacing, shape, 3D model, borders and shading, column widths, layout review.
    • Step-by-step instructions are open on every task. No need to tap the hint.
    • They still produce a full report: formatted text, styles, list, border, picture, chart, table, spelling fixed, Print Preview, saved.
    • More support: pair the student with a buddy for Missions 3 and 4, and check in with them at minutes 11 and 30.
    • Fast finishers on either route: the ⚡ Bonus challenge (drop cap and magazine footer, +10).
