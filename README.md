# Classroom Games

Three browser games with shared class leaderboards:

- **Crack the Secret Code** (Grade 8 Excel): https://crack-the-secret-code-moh-93f1.vercel.app
- **Midterm Quest** (Grade 8 ICT midterm, Unit 1): https://midterm-quest-moh-93f1.vercel.app
- **Report Rescue** (Grade 7 Word): https://report-rescue-moh-93f1.vercel.app

Add `?board` to any link for the projector leaderboard. See `CLAUDE.md` for how everything fits together.
